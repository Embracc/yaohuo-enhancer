# 妖火网增强插件

面向 [妖火网](https://www.yaohuo.me) 的油猴 / VIA 用户脚本：列表浏览、分屏预览、评论增强、发帖 UBB/图床、等级查询、自动更新检测等。  
**无 `@grant` / 无 `@require`**，自带迷你 jQuery，兼容 VIA 等轻量环境。作者：**Embrace（ID:19299）**。

当前版本：**v0.9.218**

---

## 安装

**国内（推荐，无需代理）**

```
https://ghfast.top/https://raw.githubusercontent.com/Embracc/yaohuo-enhancer/main/yaohuo-enhancer.user.js
```

备选：

```
https://gh-proxy.com/https://raw.githubusercontent.com/Embracc/yaohuo-enhancer/main/yaohuo-enhancer.user.js
```

**GitHub raw（需可访问 GitHub）**

```
https://raw.githubusercontent.com/Embracc/yaohuo-enhancer/refs/heads/main/yaohuo-enhancer.user.js
```

安装后打开妖火任意页，左下角 **⚙** 进入设置。设置内也可手动检测更新、复制安装链接。

## 功能概览

| 分组 | 能力 |
|------|------|
| **浏览** | 新标签打开帖子、列表分屏预览（右侧 iframe，可调比例/边距）、浮窗预览（列表置底+右侧悬浮）、列表时间显示 |
| **界面** | 浮动按钮（回顶 / Lv 等级 / 只看楼主）、楼主标签、发帖·回复 UBB 工具栏与图床/视频上传、按钮透明度调节 |
| **评论** | 进帖加载全部评论并楼中楼整理、复读机 +1 / 「复」复制评论、列表/评论自动加载更多、自动吃肉、图片点击放大 |
| **更新** | 自动检测（每次打开页面一次）、手动检测；国内多镜像 + 取最高版本号 |

说明：

- **Lv** 只查**当前登录用户**（昵称、ID、妖晶、经验、等级等），不是楼主。
- **复读机 +1 / 「复」复制评论**：在按钮上滑动会取消发送，减少误触。
- **VIA**：需双 `@match`（`yaohuo.me` / `*.yaohuo.me`），同源 XHR 自动带 Cookie，勿手动设 Cookie 头。

仓库：https://github.com/Embracc/yaohuo-enhancer
